Конвертер картинок в текстовые арты.
 
Пока реализовано два вида артов - из градиента ASCII символов, и блоков.

Символы разных размеров, поэтому не держат форму в чатах.
Блоки держат размер лучше.

## Использование
#### Вариант 1
- Откройте .exe программу
- Выберете вид арта
- Вставьте ссылку на файл картинки (Shift + Пкм -> Копировать как путь)
- Скопируйте арт из консоли (Ctrl+A -> Ctrl+C).

#### Вариант 2
- Перетащите все необходимые изображения на .exe файл
- Там где лежат картинки появится .txt файл со всеми артами в формате ASCII.

Проект фановый.

Но проект может остаться в виде консольного приложения в не лучшем виде, если это никому не нужно.

**Если на проекте соберётся 10 звёзд и больше**, то я сделаю из этого утилиту, которая на правую кнопку мыши (как 7z) будет создавать выбранный арт и копировать его в буфер обмена. Да и в целом буду развивать этот проект.
